## 1. 字体

字族取系统栈，macOS 上即 SF Pro + 苹方，天然原生质感：

```css
--mx-font-family: -apple-system, "SF Pro Text", "PingFang SC", "Segoe UI", Roboto, sans-serif;
```

字阶 5 级（Mac 桌面刻度，正文基准 13）：

| token | 字号/行高 | 字重 | 语义 |
| --- | --- | --- | --- |
| `--mx-font-title` | 20 / 28 | 600 | 页面标题 |
| `--mx-font-heading` | 15 / 22 | 600 | 小节标题 |
| `--mx-font-body` | 13 / 20 | 400 | 正文（基准） |
| `--mx-font-caption` | 11 / 16 | 400 | 辅助说明 |
| `--mx-font-micro` | 10 / 14 | 500 | 徽标、角标 |

## 3. 间距

4pt 网格，间距只取刻度值：

```css
--mx-space-1: 4px;   --mx-space-2: 8px;   --mx-space-3: 12px;
--mx-space-4: 16px;  --mx-space-5: 20px;  --mx-space-6: 24px;
--mx-space-7: 32px;
```

## 4. 圆角

对应 macOS 连续圆角质感，三档：

```css
--mx-radius-control: 6px;    /* 控件：按钮、输入 */
--mx-radius-card: 10px;      /* 卡片、面板 */
--mx-radius-window: 12px;    /* 窗口、浮层 */
```

## 5. 动效

```css
--mx-ease-standard: cubic-bezier(0.16, 1, 0.3, 1);  /* 标准减速曲线 */
--mx-duration-fast: 150ms;    /* hover / 按下反馈 */
--mx-duration-motion: 300ms;  /* 面板、浮层出现 */
```

动效只用于状态过渡，不做装饰动画。

## 6. 图标（Iconify 机制）

- **名称即接口**：`Glyph = "{collection}:{name}"`（Iconify 语法，如 `lucide:settings`、`mdi:folder-open`）。填入名称即可引用，图标数据按需经 Iconify API 在线加载并本地缓存（`@iconify/vue` 内建缓存）；常用集合（如 lucide）可预打包，离线兜底。
- **壳提供唯一图标组件**（`ui-shell-vue` 的 `MxIcon`）：`<MxIcon name="lucide:settings" :size="16" />`，插件不自行加载图标库。
- **渲染统一 `currentColor`**，服从主题 token；只用单色图标集。
- **尺寸两档**：16（行内 / 控件）、20（工具栏 / 空态）。
- 强制纪律见[军规 9](./界面军规.md)。
