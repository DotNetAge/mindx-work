# 界面军规

| 项 | 值 |
| --- | --- |
| 归属 | mindx-work · UI 框架（shell） |
| 状态 | 定稿（2026-09-24） |

| 生效范围 | 壳（shell-core / ui-shell-vue / electron 壳）与全部插件 |

## 一、主题军规

**军规 1 — 双主题标准**
界面只存在两套标准主题：亮色（light）与暗色（dark）。不做第三套主题，不做主题定制器。

**军规 2 — 用户三档选择**
主题选择固定三档：亮色 / 暗色 / 自动（跟随系统），默认"自动"。"自动"档监听系统外观变化实时切换（`prefers-color-scheme`）。

**军规 3 — 主题由 token 承载**
主题全部以 `--mx-*` CSS 自定义属性定义，主题切换 = 根节点替换 token 值，组件永不感知当前主题名。亮暗切换机制归壳所有，插件零参与。

**军规 4 — 禁止字面色值**
壳与插件的任何样式禁止书写字面颜色值；颜色一律 `var(--mx-*)` 或基于 token 的计算（如 `color-mix`）。

## 二、伪类军规（界面套件规则）

**军规 5 — 交互态全量显式定义**
所有可交互元素必须在样式表中**显式定义全部交互伪类**，缺一即为缺陷：

- `:hover` — 悬停
- `:active` — 按下
- `:focus-visible` — 键盘聚焦
- `:disabled` — 禁用

禁止依赖浏览器默认样式兜底；禁止用 JS 状态类（如 `.is-hover`）模拟交互态——交互状态一律用伪类表达。

**军规 6 — 伪类取色自 token**
伪类中的颜色、背景、边框必须来自 token 或其计算值，与军规 4 同源。

## 三、样式选用军规

**军规 7 — 先选主题套件，后自定义**
插件界面**首先选用主题样式**（界面套件：token 层 + 壳提供的基础控件样式），仅当套件无对应能力时才自定义样式；自定义仍受军规 3、4、6 约束。

**军规 8 — 禁止页内样式**
禁止在模板内书写内联样式（`style` 属性 / 运行时 style 对象）。样式一律经 CSS Modules 定义；唯一例外是动态数值经 CSS 自定义属性注入（如 `style="--w: 320px"`），不得拼样式字符串。

## 四、图标军规

**军规 9 — 图标纪律**
图标一律经壳的图标组件（`MxIcon`）以 Iconify 名称引用（`{collection}:{name}`），只用单色图标集、统一 `currentColor` 渲染，尺寸取 16 / 20 两档。禁止手写内联 SVG 图标，禁止引入多色图标。图标原语与加载机制见[样式原语](./样式原语.md)第 6 节。

## 五、组件库军规

**军规 10 — Element Plus 为壳特许供给的通用组件库**
Element Plus（EP）由壳单例供给：唯一声明家与消费入口都是 `@mindx-work/ui-shell-vue`（re-export 全量），插件与壳经它引入；**禁止**在插件或 app 中直接声明 `element-plus` 依赖或书写 `import '...' from 'element-plus'`（pnpm 隔离 node_modules 下是幻影依赖；多实例会造成 zIndex 计数器分裂、provide/inject 断裂、暗色双变量源）。EP 装配（`app.use(ElementPlus)`）是壳入口唯一一处。

**军规 11 — 分工边界：mx-uikit 优先**
基础控件（按钮、输入框、开关、页签、标签、下拉触发等）一律 mx-uikit；EP 仅用于 mx-uikit 未覆盖的复杂组件（date-picker、table、tree、cascader、upload 等）。同屏不混用同类控件（如同一界面 mx-btn 与 el-button 并存）。

**军规 12 — EP 取色自桥接 token**
EP 主题经壳唯一桥接表（`ui-shell-vue/src/styles/element-plus.css`）全量映射 `--el-*` → `--mx-*`，亮暗双主题随 `data-mx-theme` 自动切换。业务代码使用 EP 时禁止字面色值，颜色一律 `--el-*` 或 `--mx-*`（军规 4 延伸）；禁止在任何文件覆写 `--el-*` 变量（唯一桥原则，改桥接表即全局生效）。

**军规 13 — zIndex 分带**
mx 自绘弹层 ≤ 2100（壳设置 60 / modal 70 / tooltip·menu 1100 / 插件 FLIP 2000–2001）；EP 弹层 ≥ 3000（装配初值 `zIndex: 3000`）。新层规划必须落带内，跨带压盖视为缺陷。

## 附：与契约的分工

- 结构性约束（视图区、条目、编排语义、零文案壳、几何归壳）见[组件层契约](./组件层契约.md)。
- 本军规只管**视觉与样式的强制规则**；两份文档冲突时以契约为准并修订军规。
- 界面套件的控件层清单（按钮、输入、列表行等基础控件）随实现定稿；定稿后按军规 5 逐项验收交互态。
